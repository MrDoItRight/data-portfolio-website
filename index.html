01 / Infrastructure as code

Three-Tier
AWS Network

A cloud network you can recreate from code. I used modular Terraform to define public ingress, private application subnets and an isolated database tier across availability zones.

NAT gateways provide outbound access for private workloads. Security groups control traffic between tiers, keeping the network boundaries explicit.
